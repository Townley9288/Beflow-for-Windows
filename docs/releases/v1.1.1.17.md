# Beflow for Windows v1.1.1.17

- WEB 与 TV 画质在同一个下拉框中分别分组，默认沿用 WEB，保留 WEB 的 SDR 增强等原有选项；TV 项明确标记来源，手动选中后使用对应的 TV 视频和音轨。
- 普通下载、个人主页批量下载和多音轨均保存每个分P的来源；加入队列、编辑和暂停续传后继续使用已确认的来源。TV 读取失败时单独提示并保留可用的 WEB 画质。
- 修正 TV 账号的超级大会员识别；保留 TV 视频接口返回的真实分辨率和帧率，缺失时探测媒体头，补齐选流界面所需参数。
- 修正长篇多分P目录阶段重复解析全部视频的问题。完整读取目录后只解析尚未取得规格的分P，“当前集”模式只解析链接指定的分P。
- 解析遇到 HTTP 412 或接口错误 -352 时停止本轮请求，保留已取得的结果，显示实际就绪、失败和待解析数量，并支持稍后手动继续。
- 修正 TV 选项追加到列表时清空已有编码选择、成品大小只计算音频及无法入队的问题；解析结束后不再被延迟进度消息重新显示为运行中。

保留现有配置、登录、队列和历史记录，沿用现有下载命名与手动 CDN 设置。

TV 画质是否带有水印取决于实际视频源，本版本不承诺 TV 视频无水印。B 站接口仍可能触发风控，出现提示后需稍后手动重试。
