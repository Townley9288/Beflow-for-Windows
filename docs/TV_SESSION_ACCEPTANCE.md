## 已确认的规则

- 保留 WEB 原有画质，TV 已登录时单独读取 TV 画质，在同一画质下拉框中分组展示，默认选择 WEB。
- TV 项标记“TV”，手动选择 TV 画质后才使用 TV 视频和音频。相同规格在两个分组中各自保留，一个分P不跨会话拼接音视频。
- TV 验证或读取失败时显示独立提示，保留可用 WEB 列表；已选择 TV 的任务执行失败则停止，不自动切换 WEB，不自动重试 TV 播放接口。
- 批量规则应用于 WEB，沿用既有规格匹配策略并展示原因，不按规格自动切换到 TV。
- 普通下载、主页批量下载、多音轨来源均保存分P来源；队列执行、暂停续传和编辑继续使用已确认来源。旧队列没有分P来源字段时沿用原任务接口。
- 无需增加接口切换控件；来源显示在原有“就绪”状态位置。
- WEB 未配置时保留匿名 WEB 解析；WEB 登录失效或验证报错时停止，不改用匿名或 TV 继续。
- TV 账号卡片依据同一账号响应中的 `vip.tv_vip_status == 1` 显示“超级大会员”，不将普通会员的 `vip.label.text` 当作 TV 权益标签；登录有效与会员权益分别判断，不增加查询接口或回退。
- TV 流读取接口实际返回的 `width`、`height`、`frame_rate`；参数缺失或无效时，由内置 ffprobe 读取最多 1 MiB 媒体头取得真实参数。单条探测限时 20 秒，通过标准输入传入媒体头，不产生临时媒体文件；探测失败停止并提示手动重试，不推算参数或切换会话。
- 探测使用现有下载 CDN 设置及 Android 媒体请求头规则；手动 CDN 在当前分P和全部分P解析中均传入工具。媒体请求直连，不附带 WEB Cookie 或 TV access token，不记录签名媒体地址。
